CleanFrame developer docs

CleanFrame is a FastAPI image privacy service for metadata stripping, batch manifests, and optional background removal. This page is written for developers integrating the API or reviewing the project.

Quick Start

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python server.py

Open http://127.0.0.1:8765. FastAPI's interactive schema is available at /api/docs.

Authentication

Set API_KEY in the server environment to protect write endpoints. Do not hard-code secrets in frontend files, Docker images, or commits.

$env:API_KEY="replace-with-a-long-random-token"
python server.py

Clients may send either Authorization: Bearer <key> or X-API-Key: <key>. The browser workbench stores the key in sessionStorage only.

Endpoints

RoutePurposeOutput
GET /healthRuntime limits and optional tool availability.JSON
POST /api/stripClean one uploaded image.Image file
POST /api/strip-zipClean multiple uploaded images.ZIP with manifest.json
POST /api/remove-bgRemove background with rembg, then optionally re-encode.PNG file

Examples

Single Image

curl -X POST "http://127.0.0.1:8765/api/strip?output=png&exiftool_check=false" \
  -F "file=@photo.jpg" \
  -o photo_clean.png

Authenticated Batch ZIP

curl -X POST "http://127.0.0.1:8765/api/strip-zip?preserve_alpha=true" \
  -H "Authorization: Bearer $API_KEY" \
  -F "files=@one.jpg" \
  -F "files=@two.png" \
  -o cleanframe_batch.zip

Security Notes

CleanFrame re-encodes pixel data to remove metadata and deletes temporary files after each response. It is still an image-processing service, so host it behind HTTPS, use a long random API_KEY, keep upload limits conservative, and monitor server logs.
